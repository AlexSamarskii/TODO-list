# 📝 ToDo List на React

Простое приложение для управления задачами с возможностью добавления, удаления и отметки выполненных задач.

## 🚀 Функционал

- Добавление новых задач
- Отметка выполненных задач
- Удаление задач
- Фильтрация задач (все/активные/выполненные)
- Локальное сохранение данных (localStorage)

## 🛠 Технологии

- React 18
- TypeScript (опционально)
- CSS-модули / SCSS
- Хуки (useState, useEffect)
- LocalStorage API
